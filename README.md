# ✨ Features

- 📄 Upload Resume PDF
- 🤖 AI-Powered Resume Analysis
- 📊 ATS Resume Scoring
- 💡 Smart Suggestions for Improvement
- 💪 Strength & Weakness Detection
- 🎯 Recommended Career Roles
- 🌌 Modern Interactive Dashboard UI
- ☁️ Streamlit Cloud Deployment
- 🔐 Secure OpenAI API Integration
